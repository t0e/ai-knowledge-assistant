Cloud Architecture and Service Architecture

The AI Knowledge Assistant is engineered with a modular microservices architecture utilizing FastAPI, PostgreSQL, Redis, and Next.js.

1. RESTful API Versioning

All core API endpoints are prefixed with /api/v1. The backend uses asynchronous request handlers with lifespan management for connection pooling.

2. Asynchronous Job Processing with Redis ARQ

Heavy I/O and CPU workloads including document extraction, chunking, and embedding generation are executed asynchronously using Redis-backed ARQ workers. Worker tasks use exponential backoff retries on transient network errors.

3. Vector Storage and pgvector Indexing

Document chunks are transformed into 1536-dimensional vector embeddings and stored in PostgreSQL using the pgvector extension. Semantic vector similarity search is performed using cosine distance operators.

4. SSRF Defense in Depth

The system protects against Server-Side Request Forgery by inspecting both URL hostnames and resolved DNS IP addresses, blocking loopback, RFC1918 private subnets, cloud metadata endpoints (169.254.169.254), and internal Docker service containers.
